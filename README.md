Olist E-commerce Sales & Customer Analytics

PROJECT OVERVIEW

This project analyzes the Brazilian Olist e-commerce dataset to understand sales performance, customer purchasing behavior, delivery performance, and customer satisfaction. The objective is to transform raw data into meaningful business insights using Python, SQL, Excel, and Power BI.

PROJECT OBJECTIVES

- Analyze sales performance, revenue trends, and order patterns.
- Understand customer purchasing behavior and repeat purchases.
- Evaluate delivery performance and identify delivery delays.
- Analyze customer reviews and satisfaction levels.
- Define and calculate key business performance indicators (KPIs).
- Create interactive dashboards and provide actionable business recommendations.

DATASET

Dataset Name: Brazilian E-Commerce Public Dataset by Olist

Dataset Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains information about customers, orders, order items, products, sellers, payments, deliveries, and customer reviews.

TOOLS AND TECHNOLOGIES

Matplotlib and Seaborn: Data visualization.

MySQL: Data storage, querying, and KPI calculations.

KEY PERFORMANCE INDICATORS

- Total Revenue
- Total Orders
- Average Order Value
- Average Delivery Time
- Late Delivery Rate
- Average Customer Review Score
- Repeat Customer Rate

KPI calculations will follow documented definitions and appropriate data filters.

PROJECT LIMITATIONS

The dataset represents historical e-commerce activity and may not reflect current market conditions. Customer identification and available order history may limit repeat-purchase analysis. Relationships between delivery performance and customer reviews do not necessarily establish causation. Results depend on data quality and the definitions used for each KPI.
